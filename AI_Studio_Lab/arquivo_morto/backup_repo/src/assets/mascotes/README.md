# Mascotes — PNGs definitivos

Coloque aqui os PNGs finais dos mascotes. Eles substituem o desenho SVG
**automaticamente** (sem mexer em código), via `mascotAssets.ts`.

## Regras (docs/plano-diretor-v2.md, Parte A — inegociáveis)
- PNG com **transparência REAL** (canal alfa). JPG é PROIBIDO PARA SEMPRE.
- 512×512, personagem centralizado, margem de 10-15%.
- Comprimir antes de subir (<80KB cada, WebP opcional).

## Nomes exatos (Dragão de Fogo)
- `dragao-1-ovo.png`
- `dragao-2-filhote.png`
- `dragao-3-jovem.png`
- `dragao-4-guerreiro.png`
- `dragao-5-supremo.png`

Outros temas seguem a mesma convenção: `{tema}-{estagio}-{nome}.png`.
